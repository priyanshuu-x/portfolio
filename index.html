TicketPilot

A 4-agent customer-support system that resolves refund & order tickets end to end — and can’t be tricked into a wrong refund.

  • Supervisor, Investigator, Policy Advisor and Resolver on a stateful LangGraph, each with least-privilege access to a standalone MCP server that enforces refund rules and order ownership server-side.

P—03Gateway · Guardrails · Observability

LLM Gateway

An OpenAI-compatible routing layer that decides which model answers, what’s cached, and what never reaches a model at all.
